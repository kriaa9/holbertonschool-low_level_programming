# C - Recursion

This project covers recursion concepts in C programming.

## Learning Objectives

- Understanding what recursion is
- How to implement recursion
- When to use recursion
- When NOT to use recursion

## Requirements

- No loops allowed
- No static variables
- No standard library functions (printf, puts, etc.)
- Only `_putchar` allowed
- Betty style compliance
- Compiled with: `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`

## Tasks

0. **_puts_recursion** - Print a string using recursion
1. **_print_rev_recursion** - Print string in reverse
2. **_strlen_recursion** - Return string length
3. **factorial** - Calculate factorial
4. **_pow_recursion** - Calculate power
5. **_sqrt_recursion** - Calculate square root
6. **is_prime_number** - Check if number is prime
