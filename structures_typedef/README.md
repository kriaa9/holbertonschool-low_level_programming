# C - Structures, typedef

## 📚 Project Description

This project explores structures and typedef in C programming. You'll learn how to define and use structures to group related data, and how typedef creates aliases for data types.

---

## 🎯 Learning Objectives

At the end of this project, you should be able to explain **without Google**:

### **What are structures?**
Structures (structs) are user-defined data types that allow you to combine data items of different types under a single name.

**Syntax:**
```c
struct structure_name {
    type member1;
    type member2;
    ...
};
