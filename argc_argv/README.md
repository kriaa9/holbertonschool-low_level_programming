# C - argc, argv

This project explores command line arguments in C programming.

## Learning Objectives

- How to use arguments passed to your program
- Two prototypes of main and when to use each
- How to use `__attribute__((unused))` or `(void)` to compile with unused variables

## Requirements

- Allowed editors: vi, vim, emacs
- Compiled on Ubuntu 20.04 LTS using gcc with flags: `-Wall -Werror -Wextra -pedantic -std=gnu89`
- All files end with a new line
- Betty style compliant
- No global variables
- Max 5 functions per file
- Standard library allowed

## Prototypes

All function prototypes are in `main.h`

## Tasks

0. **0-whatsmyname.c** - Prints program name
1. **1-args.c** - Prints number of arguments
2. **2-args.c** - Prints all arguments
3. **3-mul.c** - Multiplies two numbers
4. **4-add.c** - Adds positive numbers
