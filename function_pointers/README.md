# C - Function Pointers

## 📚 Project Description

This project explores function pointers in C - one of the most powerful and flexible features of the language. You'll learn how to use functions as data, pass them as arguments, and create more dynamic and reusable code.

### **What are function pointers?**

Function pointers are variables that store the address of a function. Just like regular pointers store addresses of data, function pointers store addresses of executable code.
